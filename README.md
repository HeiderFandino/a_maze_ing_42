##Description
The A-Maze-ing project consists in generating a maze via an algorithm and visually representing it in the terminal. The maze has to take variables from te user such as the height and width of the maze, the entry and exit coordinates, the seed and wether or not the maze is perfect. The maze has to be solvable regardless of the perfect variable.
